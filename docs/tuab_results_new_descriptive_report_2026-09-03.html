6. 配置、实验语义与限制

以下内容用于解释结果如何产生，不把分类性能等同于直接去噪质量。

实验链路

  1. Script 17：连续 TUAB recording 上的 phase-gated Wiener 分量缓存。
  2. Script 18：重建 raw，并保存 raw / specific / coherent 及 38 通道 specific_coherent。
  3. Script 19：四个独立 EEGNet 条件，recording-level 聚合；checkpoint 按 validation recording AUPRC 选择，阈值按 validation balanced accuracy 选择。
  4. Script 20：四个独立 XGBoost 条件，base211 特征；recording-level AUROC/AUPRC 作为排序指标，阈值来自验证集 macro-F1 优化。

解释边界

  • 这是单一固定划分上的描述性比较，没有置信区间、跨随机种子重复或显著性检验。
  • AUROC/AUPRC 是阈值无关的跨模型主比较；本报告将 F1 统一重算为 macro-F1。原始 EEGNet 指标文件中的 f1 是 normal 正类的 binary-F1，XGBoost 的 f1 是 macro-F1。
  • 分类下游效用是间接评价 instrument，不等于 ECMAD 的直接信号质量或生理正确性证明。
  • 结果目录当前 5 个 phase × 4 条件 × 2 模型的关键预测与 SHAP 文件均完整：是。
