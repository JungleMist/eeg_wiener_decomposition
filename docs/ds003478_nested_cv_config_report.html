预处理与 ECMAD 条件

通道固定顺序　FP1, FP2, F7, F3, Fz, F4, F8, T3, C3, Cz, C4, T4, T5, P3, Pz, P4, T6, O1, O2。读取时以 T7/T8/P7/P8 对应 T3/T4/T5/T6。

  1. 从 EEGLAB .set/.fdt 读取静息态记录，抽取 19 通道并做 19 导平均重参考。执行 0.5–40 Hz IIR 带通，再重采样至 125 Hz。
  2. 从记录起点提取互不重叠的 20 秒窗（2,500 点）；全窗任一通道的绝对峰值超过 200 µV 即剔除。所有条件共用该保留掩码。raw 保存预处理后、ECMAD 分解前的数据。
  3. 对连续通过剔除规则的片段分别执行 ECMAD。每个阈值独立从同一原始片段计算，20 秒 Hann 加权窗，50% 重叠相加，避免分解跨越剔除间隙。coherent = raw − specific。

ECMAD 使用通道组矩阵自适应向量 Wiener 分解（phasegated），以零相位为中心做相位门控。估计窗 500 点（4 秒），频带 0.5–40 Hz，相干度阈值 0.15，滤波器幅值上限 50，重叠通道组按相干度加权融合。5–20 Hz 保护频带从相干候选评分和相干重建中排除。群组功率门关闭。

受试者级嵌套交叉验证

  1. 外层按 participant_id 排序，依次留出 1 名受试者（索引 0–105），剩余 105 名用于开发。
  2. 在每个外层开发集上使用五折分层交叉验证，shuffle=True，随机种子 42。受试者的所有记录与 EEG 窗始终同折。两种模型与 13 个条件共享划分。
  3. 各内层训练、验证只使用开发集。模型选择结束后，将五个验证折的受试者预测合并，用于为该方法、条件及外层折冻结阈值。训练入口在选择结束后才加载外层测试矩阵。准备阶段的缓存预先按记录独立生成。
  4. 外层测试使用五个内层模型集成。先对五模型的 EEG 窗概率等权平均，再对该受试者的保留 EEG 窗等权平均。记录有不同窗数时，各记录对受试者概率的权重随窗数变化。用冻结阈值生成外层二分类标签。

EEGNet 内层验证用于早停和阈值选择，XGBoost 内层验证用于阈值选择。外层留出用于评估整套决策流程。13 条件是独立评估的比较项，依据外层表现再挑选最佳条件会带来选择偏差。

分类指标与 SHAP

按方法和条件收齐各 106 名受试者的外层折外预测，再计算 AUROC、average precision（汇总列 auprc）、balanced accuracy 和高 BDI 正类 F1。comparison.csv 预期 26 行；其 F1 与 XGBoost 选阈值所用 macro F1 定义不同。

XGBoost对完整 booster 应用 TreeSHAP，解释外层全部保留窗。归因为 log-odds 尺度。特征顺序按 base211_conn80，拼接组按两组成分分别排列。outer_shap.npz（归因矩阵）和 outer_shap_epochs.csv（窗索引）。

嵌套汇总脚本只生成分类指标和折外预测。若要做总体成分比较，可从各折 SHAP 先在受试者内对窗及五个模型等权汇总，再在参与者间平均。在拼接组内分别计算 specific 与 coherent 的平均绝对归因及其占比，并在同模型内对照各阈值。两种解释尺度和采样范围不同，归因绝对值应分别报告。分类效能与归因反映 BDI 分组任务，单凭这些结果无法判断成分的生理或伪迹来源。

CUDA 服务器执行方式

在服务器的项目根目录执行。使用 Python 3.11 的 eeg_pipeline 环境及 CUDA 版 PyTorch 和 XGBoost。仓库 requirements.txt 记录依赖版本。缓存与结果路径以下均相对于项目根目录，运行账户须有写权限。

conda activate eeg_pipeline
python -m pip install -e .
export CUDA_VISIBLE_DEVICES=0
export MPLBACKEND=Agg

python scripts/ECMAD.py prepare \
  --data-dir /home/sujunhang/Data/ds003478-1.1.0 \
  --output-dir cache/ecmad_cache --workers 8
python scripts/prepare_ds003478_nested_features.py \
  --cache cache/ecmad_cache --workers 8

bash <<'BASH'
set -euo pipefail
for method in eegnet xgboost; do
  for ((fold=0; fold<106; fold++)); do
    python scripts/run_ds003478_nested_cv.py \
      --cache cache/ecmad_cache \
      --output results/ds003478-1.1.0-nested \
      --method "$method" --outer-index "$fold" --workers 4
  done
done
python scripts/summarize_ds003478_nested_cv.py \
  --cache cache/ecmad_cache --output results/ds003478-1.1.0-nested
BASH

多 GPU 可在缓存准备结束后按方法提交两个 Slurm array（每组 0-105，每任务一块 GPU），把 --outer-index 设为 "$SLURM_ARRAY_TASK_ID"，并让调度器分配 GPU。全部任务结束后运行汇总。预估资源时，需同时考虑拟合时间、五折数据载入峰值内存，以及内层验证预测、校验标记和 SHAP 的磁盘与 inode 用量。

中断后用原命令、原缓存和原结果路径重启，无需额外 --resume。已校验的条件和外层解释会跳过。配置或实现不匹配时应使用独立结果目录。EEGNet 中断期间的临时文件会留作续跑；完成后预测、指标与归因仍可复核，重新推理则需要重新拟合。
